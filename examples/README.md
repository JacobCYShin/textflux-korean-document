# Demo Inputs

`demo-inputs/` holds one synthetic Korean form and four matching binary masks.
Every measurement recorded in [docs/findings.md](../docs/findings.md) used these files.

They exercise the content path only:

- Hangul glyph conditioning
- target-field mask alignment
- date and amount punctuation
- result retention and review flow

They are **not** a real-document benchmark and they do **not** exercise handwriting-style transfer.
The runner has no style-conditioning input; see
[docs/style-conditioning-boundary.md](../docs/style-conditioning-boundary.md).

## Field geometry

The form is 1280 x 1810. All four masks share the same field height.

| Mask | Field box | Aspect |
| --- | --- | --- |
| `demo_name.png` | 711 x 81 px at (420, 480) | 8.8 : 1 |
| `demo_purpose.png` | 711 x 81 px | 8.8 : 1 |
| `demo_date.png` | 711 x 81 px | 8.8 : 1 |
| `demo_amount.png` | 711 x 81 px | 8.8 : 1 |

The printed row label `성명` occupies x = 78 ~ 221 on the `demo_name` row.
That distance is what sets `--context-x` when cropping; see
[docs/decision-log.md](../docs/decision-log.md#--context-x-45--가장-중요한-값).

## Use

```bash
mkdir -p "$INPUTS" && cp -a "$BENCH/examples/demo-inputs/." "$INPUTS/"
```

Then follow [docs/reproduce.md](../docs/reproduce.md).

`demo-manifest.jsonl` runs the four fields against the unmodified masks — the pre-correction
condition that produced the aspect-ratio finding. Aspect-fitted and cropped variants are
generated by `scripts/make_field_masks.py` and `scripts/make_crop_inputs.py`.

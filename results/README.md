## 포함된 것

### `aspect-ratio-evidence.png`

**1차 요인(마스크 종횡비)의 직접 증거.** 8케이스, 시드 42.

각 케이스마다 두 장이 짝지어 있다.

| 테두리 | 내용 |
| --- | --- |
| 파랑 | 모델에 준 조건 그림 (글리프 띠의 잉크 영역) |
| 빨강 | 실제 출력 (마스크 영역을 잘라낸 것) |

위쪽 4건은 **종횡비 불일치**, 아래쪽 4건은 **정합** 상태다.
왼쪽에 글리프 종횡비와 박스 종횡비를 함께 적었다.

읽는 법 — 위에서 아래로 내려갈수록 두 비율의 차이가 줄고, 출력이 난수에서 거의 정확으로 바뀐다.

| 케이스 | 글리프비 vs 박스비 | Δ | 출력 |
| --- | --- | --- | --- |
| `demo-hangul-basic-001` | 2.9 vs 8.8 | 5.9 | 전부 불일치 |
| `demo-hangul-final-001` | 3.9 vs 8.8 | 4.9 | 앞 2자만 |
| `demo-date-001` | 7.4 vs 8.8 | 1.4 | 한글로 출력 |
| `demo-amount-001` | 8.5 vs 8.8 | 0.3 | **15/16자** — 쉼표 1개 누락 |
| `probe-hangul-4-001` | 3.9 vs 4.0 | 0.1 | 3/4자 (`기→지`) |
| `probe-zh-4-001` | 4.2 vs 4.0 | 0.2 | 3/4자 |
| `probe-en-4-001` | 3.3 vs 4.0 | 0.7 | 한글로 출력 |
| `probe-fit-count-001` | 9.0 vs 8.8 | 0.2 | 앞 2자·뒤 2자만 |

`demo-*` 4건은 원본 마스크 그대로, `probe-*` 4건은 마스크 폭을 글자 수에 맞춘 뒤의 결과다.

## 포함되지 않은 것

교정 후 본 측정(`crop-probe-v3`, `jamo-probe-v1`, `guid-15`, `guid-7`, `steps-50`)의
판독 시트는 실행 환경에 남아 있고 이 저장소에 없다.

`paste_crop_results.py`가 스위트별로 다음 위치에 만든다.

```text
$OUTPUT/runs/<suite>/review-sheet.png
```

가져올 파일:

| 파일 | 담고 있는 것 |
| --- | --- |
| `runs/crop-probe-v3/review-sheet.png` | 교정 후 성적표 15케이스 × 3시드 |
| `runs/jamo-probe-v1/review-sheet.png` | 자모 최소대립쌍 16케이스 × 3시드 |
| `runs/guid-15/review-sheet.png` | `guidance 15` |
| `runs/guid-7/review-sheet.png` | `guidance 7.5` |
| `runs/steps-50/review-sheet.png` | `steps 50` |

**`jamo-probe-v1`이 가장 정보량이 많다.** 받침 유무 대조와 출력 끌개 현상이 한 장에 들어 있다.

시트는 합성 데모 서식지 기반이므로 실제 문서 내용을 담지 않는다.

---

## 판독 기준

**문자열 완전 일치.** 부분 정확은 0으로 계산한다.
`금융기관` → `금융지관`은 4자 중 3자가 맞았지만 0점이다.

시드별로 세어 `n/3`으로 기록한다. 1시드만 보면 계통적 결함과 샘플링 잡음을 구분할 수 없다.

시트를 읽기 전에 해당 실행의 `outputs_my/rendered/rendered_0001.png`를 확인한다.
조건 그림 자체가 잘못됐으면 출력 품질을 모델 능력으로 해석할 수 없다.
